
# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability in SPY BUG, please report it responsibly.

Please include:

- Description of the vulnerability
- Steps to reproduce
- Potential security impact
- Suggested remediation

## Responsible Disclosure

Please do not publicly disclose an unresolved vulnerability.

Do not include real credentials, session cookies, or private user information in reports.

## Scope

This policy applies to vulnerabilities in the SPY BUG project itself.

For third-party targets, obtain explicit authorization before conducting security testing.
